# aurora-assets

Runtime assets for the Aurora loader. The script pulls these on first launch and
writes them into the executor workspace, so nothing has to be installed by hand.

    fonts/   Pricedown.otf  ChaletLondon.ttf  ChaletComprime.ttf  Griffiths.otf
    art/     wedge.png  arc.png

Fetched over raw.githubusercontent.com, cached on disk after the first run.
